# How to demo and sell this

Use a synthetic workspace with working website capture, not customer data. Explain available channels accurately: website forms are exercised here; Meta/Gmail need configured/sandbox provider verification; Google Ads, Instagram DMs and a shared WhatsApp inbox are not ready claims.

## Five-minute clinic/coaching demo

1. **0:00–0:45 — “No enquiry gets forgotten.”** Open the dashboard and today's follow-ups. Show date/owner filters and current-status labels. Use treatment interest/course interest as a configurable field rather than a clinical record/student ledger.
2. **0:45–1:30 — Capture and ownership.** Submit the hosted website enquiry form. Show its real lead, original campaign/source and configured owner. Repeat enquiry dedupe preserves the first touch. Do not simulate Meta/Google ingestion and describe it as live.
3. **1:30–2:45 — Follow up on a phone.** Open Lead Detail; use the next-step card, inspect Call/WhatsApp actions, log the conversation, add a note and schedule/complete a follow-up. Actual WhatsApp/telephony requires the user's device; never send a demo message to a real customer.
4. **2:45–3:45 — Move toward an outcome.** Qualify, then convert to contact/company/deal. Show pipeline stage rules, won/lost and activity history. For clinics demonstrate consultation inquiry handling; for coaching demonstrate counselling/demo/admission interest. Avoid promising scheduling, fee collection or clinical charting.
5. **3:45–5:00 — Owner trust.** Show real source performance, history-based funnel, response time/compliance and a permission-controlled CSV. Explain period/currency definitions and show how to configure team access and reusable templates.

## Strength by module

| Module | Concrete value to demonstrate |
|---|---|
| Dashboard | A focused starting point for work and owner visibility |
| Leads | Guided next action and one record for contact details/history |
| Campaigns | Original attribution tied to leads and outcome metrics |
| Pipeline | Clear stages with value, stale-work prompts and won/lost discipline |
| Tasks | A daily queue that records the completed conversation |
| Contacts/Companies | Conversion without retyping and scoped business relationships |
| Templates | Personal/shared reusable wording with validated variables (inherited work must be released separately) |
| Integrations | Real website form capture, assignment and dedupe; clear setup status |
| Reports | Numbers backed by workspace records, exact source links and export permissions |
| Settings | Team roles, India time/currency/phone conventions and real setup actions |

Positioning and price are hypotheses from [research](01-market-research.md), not validated sales results. Do not quote the removed conversion multiplier, claim automated WhatsApp delivery, promise missing billing/scheduled reports, or call the whole app market-ready. Lead with the workflow already verified.
